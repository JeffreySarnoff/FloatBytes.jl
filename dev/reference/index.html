Types and formats

FloatBytes.FloatByte — Type
FloatByte{K,P,S<:Signedness,D<:DomainKind} <: AbstractFloat

One-byte floating-point value per IEEE P3109 draft 1: bitwidth K ∈ 3:8, precision P, signedness marker S, domain marker D. Users normally use the 120 exported aliases (Binary8p4se, …) rather than the raw parameters. Canonical-byte invariant: bits above K are zero for every native value.

source
FloatBytes.SignedFormat — Type

SignedFormat: signedness marker Σ = Signed in FloatByte{K,P,S,D} (sign bit present; −Inf representable in extended domains).

source
FloatBytes.UnsignedFormat — Type

UnsignedFormat: signedness marker Σ = Unsigned (no sign bit; no negative values).

source
FloatBytes.FiniteDomain — Type

FiniteDomain: domain marker Δ = Finite — no infinities in the datum set.

source
FloatBytes.ExtendedDomain — Type

ExtendedDomain: domain marker Δ = Extended — +Inf (and −Inf when signed) are code points.

source
FloatBytes.FORMAT_ALIASES — Constant
FORMAT_ALIASES

All 120 format aliases in canonical lattice order (format_id order): K ascending; Signed before Unsigned; P ascending; Finite before Extended.

quantize(F, x, ρ = DEFAULT_PROJECTION; entropy = nothing, index = 0) -> F

Mathematical construction: project real x into format F under ρ. This is the visible projecting constructor; fromcode is the raw one.

source
FloatBytes.fromcode — Function
fromcode(T, code::Integer) -> T

The only safe code-identity constructor. Range-checked; reinterpret into a FloatByte is documented unsafe and confined to this file and the dense execution lowering.

source
FloatBytes.codepoint — Function
codepoint(x::FloatByte) -> UInt8

The raw code point of x (the canonical byte; bits above K are zero).

source
FloatBytes.isvalidcode — Function
isvalidcode(T, code::Integer) -> Bool

Whether code is in 0:2^K - 1 for format T.

source
FloatBytes.decode — Function
decode(x::FloatByte) -> Float64

Exact decoded value (NaN, ±Inf for specials). One const-Memory load plus a bounds-elided indexed read; the offset folds per alias.

A projection specification ρ = (rounding mode, saturation mode).

FloatBytes.DEFAULT_PROJECTION — Constant
DEFAULT_PROJECTION

The immutable package default ρ: (NearestTiesToEven, SatNone). Used by the projecting constructors and the Base operator surface unless overridden with with_projection.

source
FloatBytes.with_projection — Function
with_projection(f, ρ)

Run f() with the Base-operator projection scope set to ρ. Outside the performance interface: explicit apply(op, Fr, ρ, ...) is the fast path; only the Base-operator adapters read this scope. No mutable global numerical policy exists anywhere.

source
FloatBytes.NearestTiesToEven — Type

NearestTiesToEven(): round to nearest; ties to the even code (draft §4.7.4; for P == 1 formats evenness is defined on the code point). The package default.

source
FloatBytes.NearestTiesToAway — Type

NearestTiesToAway(): round to nearest; ties away from zero.

source
FloatBytes.TowardPositive — Type

TowardPositive(): directed rounding toward +∞.

source
FloatBytes.TowardNegative — Type

TowardNegative(): directed rounding toward −∞.

source
FloatBytes.TowardZero — Type

TowardZero(): directed rounding toward zero (truncation).

source
FloatBytes.ToOdd — Type

ToOdd(): round-to-odd — truncate, then force the kept code odd when inexact.

source
FloatBytes.StochasticA — Type

StochasticA(N): stochastic rounding, variant A of draft §4.7.4 — round away iff ⌊ν·2^N⌋ + R ≥ 2^N for the supplied N-bit entropy value R. N ∈ 1:63; this build implements N ≤ 32.

source
FloatBytes.StochasticB — Type

StochasticB(N): stochastic rounding, variant B — ⌊ν·2^(N+1)⌋ + 2R + 1 ≥ 2^(N+1).

source
FloatBytes.StochasticC — Type

StochasticC(N): stochastic rounding, variant C — RNITE(ν·2^N) + R ≥ 2^N.

source
FloatBytes.SatFinite — Type

SatFinite(): out-of-range results (including infinities) clamp to the extremal finite values.

source
FloatBytes.SatPropagate — Type

SatPropagate(): representable infinities propagate; finite overflow clamps to the extremal finite values.

source
FloatBytes.SatNone — Type

SatNone(): draft §4.7.5 default behavior — overflow goes to ±Inf where representable (NaN in finite domains and for negative results in unsigned formats), except that a rounding direction pointing inward forces the extremal finite value.

Applying operations

FloatBytes.apply — Function
apply(op, Fr, ρ, xs...; entropy = nothing, index = 0) -> Fr

Public operation entry point. Fr is the result format, ρ the projection specification. Operands are FloatByte values (heterogeneous formats allowed). entropy is required for stochastic ρ: either a raw UInt64 word (top N bits are consumed) or an IndexedEntropy keyed by index. An unsupported operand is a MethodError, never a silent fall-through to host arithmetic.

source
FloatBytes.defined_code — Function
defined_code(op, Fr, ρ, entropy::UInt64, xs::FloatByte...) -> UInt8

The internal seam: one semantic pipeline — code-point special rows in the draft's order, exact auxiliary computation over the closed extended reals, one final projection. A table entry is a call to this function.

Entropy contract: deterministic modes ignore the word; stochastic modes consume exactly the word passed (its top N bits), including for exact and special results. entropy = 0 under a stochastic mode is legal input, not a sentinel.

entropy_word(ie, index, slot, ::Val{N}) -> UInt64

The top-N-bit entropy value R < 2^N for one logical output. N is a Val so 64 - N folds to a constant shift.
